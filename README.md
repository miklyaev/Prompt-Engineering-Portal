# Prompt Engineering Portal

Интерактивная образовательная платформа для изучения и практики промпт-инжиниринга. Проект включает в себя теоретические материалы и разнообразные типы тестов для закрепления навыков.

## 1. Технологии

Проект построен на современном стеке фронтенд-разработки:

*   **React 19 & TypeScript**: Использование последней версии React для обеспечения высокой производительности и строгой типизации кода.
*   **Vite**: Быстрый инструмент сборки, обеспечивающий мгновенную перезагрузку при разработке.
*   **Tailwind CSS 4**: Новейшая версия CSS-фреймворка для быстрой и гибкой стилизации интерфейса без написания лишнего CSS-кода.
*   **Framer Motion**: Библиотека для создания плавных анимаций и интерактивных переходов между вопросами тестов.
*   **Lucide React**: Набор легких и красивых иконок.
*   **React Router 7**: Мощная маршрутизация для навигации между страницами курсов и тестов.

**Почему эти технологии?**
Выбор обусловлен необходимостью создать быстрый, отзывчивый и визуально приятный интерфейс для обучения, где интерактивность (анимации, мгновенная обратная связь в тестах) играет ключевую роль.

## 2. Компоненты и архитектура

Проект разделен на страницы (`src/pages`) и переиспользуемые компоненты (`src/components`).

### Основные страницы:
*   **HomePage**: Приветственный экран с обзором возможностей.
*   **ArticlesPage**: Список обучающих материалов и статей.
*   **TestsPage**: Основной движок тестирования, который динамически подгружает нужный тип вопроса.

### Система тестов (Components):
Каждый тип вопроса вынесен в отдельный компонент для удобства поддержки:
*   `SingleChoice`: Выбор одного варианта.
*   `MultipleChoice`: Выбор нескольких правильных ответов.
*   `MatchPairs`: Интерактивное сопоставление терминов и определений.
*   `FillTheBlank`: Ввод пропущенного слова в тексте.
*   `TrueFalse`: Быстрая проверка утверждений.
*   `OrderSteps`: Расстановка этапов промпта в правильном порядке.
*   `TimerMultipleChoice`: Тестирование на время для проверки скорости реакции.

Данные для всех тестов хранятся в формате JSON (`src/data/tests.json`), что позволяет легко добавлять новые вопросы без изменения кода.

## 3. Как развернуть проект локально

Для запуска проекта вам понадобится установленная [Node.js](https://nodejs.org/).

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <url-репозитория>
    cd Prompt-Engineering-Portal
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    ```

3.  **Запустите сервер для разработки:**
    ```bash
    npm run dev
    ```

4.  **Откройте проект:**
    Перейдите по адресу `http://localhost:5173` в вашем браузере.

5.  **Деплой:**
    Проект опубликован в интернете по адресу `http://prompt.mikser-nvkz.ru`.

## 4. Как попробовать (User Guide)

1.  **Главная страница**: После открытия вы увидите приветствие. Нажмите на кнопку "Начать обучение" или выберите раздел в меню.
2.  **Статьи**: Перейдите в раздел "Статьи", чтобы изучить теорию промпт-инжиниринга.
3.  **Тесты**:
    *   Перейдите в раздел "Тесты".
    *   Выберите любой доступный тест (например, "Основы промптов").
    *   **Что произойдет**: Появится первый вопрос с анимацией.
    *   Попробуйте выбрать ответ. Если ответ верный — кнопка подсветится зеленым, если нет — красным с пояснением.
    *   В верхней части экрана вы увидите **ProgressBar**, который заполняется по мере прохождения.
    *   В конце теста вы получите результат с итоговым баллом.
